3. Ontology / Knowledge Graph / Neo4j

Ontology는 Entity와 관계의 의미체계를 정의하고 확률은 계산하지 않는다. 실제 Fact·Evidence·방향·강도·Confidence·Time Lag·Regime은 Knowledge Graph와 인과·확률 계층에서 관리한다.

AFFECTS properties: direction, base_strength, confidence, lag_min_hours, lag_max_hours, regime_scope, condition_expression, evidence_count, model_version

10. Test Strategy

테스트는 UI가 열리는지가 아니라 Factor/Event 입력에 대해 예상 State, Causal Path, Scenario, Probability Range, Confidence, Decision이 나오는지를 검증한다.
  • Unit Test: 각 Engine schema/rule
  • Causal Test: shock이 예상 path로 전파되는지
  • Temporal Test: 1D/1W/1M/1Y 효과가 올바른지
  • Consistency Test: 불가능/모순 scenario 거부
  • Explainability Test: 모든 probability delta 재현
  • Anti-overfit Test: historical adjustment cap
  • Regression Test: model/graph 변경 후 Golden Case 유지
  • Forward Test: 실제 시장 Calibration
