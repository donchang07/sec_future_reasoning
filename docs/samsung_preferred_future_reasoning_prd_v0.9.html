삼성전자우 AI 미래추론 시스템 PRD v0.9

19개 Reasoning Engine을 중심으로 한 실행 가능한 추론 Architecture

0. 핵심 원칙

Neo4j, Supabase, Factor Registry, Vercel UI는 제품의 핵심이 아니라 Reasoning Engine을 지원하는 Infrastructure다. 동일 Input을 주었을 때 개발자가 동일한 추론 단계와 구조화된 중간 산출물을 재현할 수 있어야 한다.
REAL WORLD → Data Interpretation → Event Understanding → Expectation/Surprise → Priced-in → Situation → State → Hypothesis → Causal Expansion → Interaction → Actor/Reflexivity → Constraint/Identity → Temporal → Historical Analogy → Challenger → Scenario → Consistency → Simulation → Probability/Calibration → Meta-Reasoning/Explanation → Decision → Reality → Review → Learn

1. 공통 Engine Contract

모든 Engine은 Input, Internal Process, Output, Memory Read, Memory Write, Confidence/Failure, Next/Retry를 가진다. 필수 Evidence가 없으면 값을 임의 생성하지 않고 insufficient_evidence를 반환한다.

{run_id, as_of, horizon, data_cutoff, ontology_version, graph_version, model_version, factor_signals, events, situation, module_states, hypotheses, causal_paths, interactions, actors, constraints, temporal_paths, historical_evidence, challenge, scenarios, simulation_results, forecast, meta_check, decision}

2. 19개 Reasoning Engine 상세

1. Data Interpretation Engine

INPUT
검증된 raw observations

READ
Supabase factor_observations, Factor Registry
PROCESS
level, Δ1D/5D, velocity, acceleration, percentile, z-score, freshness를 계산한다. Unknown과 Neutral을 구분한다. Horizon별 transform을 적용한다.
OUTPUT
FactorSignal[]

WRITE
factor_signals

NEXT
Event Understanding

2. Event Understanding Engine

INPUT
공시·뉴스·공식 Event

READ
Ontology, Source Registry
PROCESS
LLM structured extraction으로 actor, event_type, magnitude, direction, duration, affected factors를 추출하고 Ontology로 검증한다.
OUTPUT
StructuredEvent[]

WRITE
events, evidence

NEXT
Expectation/Surprise

3. Expectation & Surprise Engine

INPUT
StructuredEvent + consensus

READ
consensus/event history
PROCESS
Actual-Expected, revision, guidance surprise를 계산한다. 예상치가 없으면 uncertainty를 명시한다.
OUTPUT
SurpriseObject

WRITE
event_surprises

NEXT
Priced-in

4. Priced-in Estimation Engine

INPUT
Surprise + pre-event market path

READ
futures, yields, prices, positioning proxy
PROCESS
시장이 Event를 이미 얼마나 반영했는지 0..1로 추정하고 Fundamental impact에서 중복 반영분을 제거한다.
OUTPUT
priced_in_ratio, residual_shock, confidence

WRITE
priced_in_estimates

NEXT
Situation

5. Situation Understanding Engine

INPUT
FactorSignals, Events, residual shocks

READ
current graph, prior situation
PROCESS
dominant themes, positive/negative forces, 충돌, structural-change 후보를 LLM+rules로 요약한다. 예: Strong Fundamental + Weak Liquidity.
OUTPUT
SituationState

WRITE
situation_states

NEXT
State Estimation

6. State Estimation Engine

INPUT
Situation + module observations

READ
Factor Registry, recent states
PROCESS
Macro, AI Demand, Memory, Supply, Earnings, Capital Flow, Valuation, Preferred, Market Regime 각각 -100..100 State, momentum, confidence를 계산한다. 단순 평균하지 않는다.
OUTPUT
ModuleState[9]

WRITE
module_states

NEXT
Hypothesis

7. Hypothesis Generation Engine

INPUT
Situation, ModuleStates, Horizon

READ
Domain knowledge, past hypotheses
PROCESS
Ontology/Graph 범위 안에서 상승·하락·횡보 Main/Alternative Hypothesis를 생성한다. 예: Memory wins, Macro wins, Balance.
OUTPUT
Hypothesis[] + falsification conditions

WRITE
hypotheses

NEXT
Causal Expansion

8. Causal Expansion Engine

INPUT
Hypothesis, Horizon, Regime

READ
Neo4j graph/version
PROCESS
Graph traversal로 관련 outgoing paths를 확장한다. confidence, horizon lag, regime 조건을 필터링하고 depth 제한·중복 path 제거를 수행한다.
OUTPUT
CausalPath[]

WRITE
causal_path_runs

NEXT
Interaction

9. Interaction Reasoning Engine

INPUT
CausalPaths, ModuleStates

READ
interaction rules/history
PROCESS
상쇄·증폭, threshold, nonlinear effect, double counting, path competition을 탐지한다. 금리 Regime에 따라 Memory 효과가 달라지는 식의 modifier를 적용한다.
OUTPUT
AdjustedPath[], ConflictSet

WRITE
interaction_runs

NEXT
Actor/Reflexivity

10. Actor & Reflexivity Engine

INPUT
AdjustedPaths + actor states

READ
Fed/Foreign Investor/Company/Hyperscaler profiles
PROCESS
Actor의 objective, constraint, likely action을 추정하고 momentum, forced selling, feedback 등 Reflexivity를 반영한다.
OUTPUT
ActorResponse[], ReflexiveLoop[]

WRITE
actor_runs

NEXT
Constraint/Identity

11. Constraint & Identity Engine

INPUT
ActorResponse, scenario variables

READ
financials, capacity facts
PROCESS
Fab capacity, yield, debt capacity, cash flow, supply-demand, accounting identity 등 물리·재무적으로 불가능한 경로를 차단한다.
OUTPUT
ConstraintResult[], ValidPath[]

WRITE
constraint_runs

NEXT
Temporal

12. Temporal Reasoning Engine

INPUT
Valid paths + Horizon

READ
Edge lag history
PROCESS
lag, duration, decay, acceleration을 적용한다. 같은 Edge를 1D/1W/1M/1Y에서 다르게 평가한다.
OUTPUT
TemporalPath[] + effect_by_horizon

WRITE
temporal_runs

NEXT
Historical Analogy

13. Historical Analogy Engine

INPUT
Current state vector, Horizon, Regime

READ
Prediction Journals, Experience Store
PROCESS
유사사례를 검색하고 similarity, recency, sample size, regime match를 계산한다. Historical influence cap을 적용한다.
OUTPUT
HistoricalEvidence + allowed_adjustment

WRITE
analogy_runs

NEXT
Challenger

14. Challenger Engine

INPUT
Main hypothesis, paths, history

READ
independent evidence, alternate history
PROCESS
가장 강한 반대가설과 반증 Evidence를 생성한다. 사용자/AI confirmation bias와 이전 예측 방어성향을 검사한다.
OUTPUT
ChallengeReport

WRITE
challenge_runs

NEXT
Scenario Generation

15. Scenario Generation Engine

INPUT
Hypotheses, TemporalPaths, Challenge

READ
constraints, distributions
PROCESS
Base/Upside/Downside/Tail/User-defined Scenario를 구조화된 변수 범위와 narrative로 생성한다.
OUTPUT
Scenario[]

WRITE
scenarios

NEXT
Consistency Validation

16. Scenario Consistency Validation Engine

INPUT
Scenario[]

READ
constraints, identities, causal rules
PROCESS
회계·인과·시간·Actor 반응의 내부 모순을 검사한다. 실패 Scenario는 reject 또는 Scenario Generation으로 돌려보낸다.
OUTPUT
ValidatedScenario[] + rejection reasons

WRITE
scenario_validation

NEXT
Simulation

17. Simulation Engine

INPUT
ValidatedScenario + distributions + graph

READ
time-series, causal graph
PROCESS
Python numerical simulation, causal propagation, 필요시 Monte Carlo/Agent iteration으로 Horizon별 outcome distribution을 생성한다.
OUTPUT
SimulationResult[]

WRITE
simulation_runs

NEXT
Probability

18. Probability, Aggregation & Calibration Engine

INPUT
SimulationResults, HistoricalEvidence, Challenge

READ
calibrator versions, prior
PROCESS
Scenario likelihood를 통합하고 up/down/flat을 normalize한다. Calibration을 적용하고 Prior→Evidence→Interaction→History→Challenger→Calibration의 모든 delta를 저장한다.
OUTPUT
ForecastProbability + Contributions

WRITE
forecasts, forecast_contributions

NEXT
Meta-Reasoning
